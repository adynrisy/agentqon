Model combos

A combo is a named chain of models. Pin a combo in the model picker — or map a model-name pattern to one below — and when a provider fails, runs out of quota, or stops answering, the call moves to the next model in the chain automatically; the move is written into the mission's minutes. The Auto combo is always in the picker: every connected model, scored live.

Model mappings

When a run asks for a model whose name matches a pattern, the mapped combo serves it instead. Patterns use * as a wildcard (for example gpt-*). The lowest priority number wins.

Workbench

Home > Advanced > Workbench. Projects, saved drafts, schedules, approvals waiting for you, and system health — in one place. Leaving this page never stops a mission: missions keep running, and you are told here when they finish, fail, or wait for approval.

Display — text size, theme, motion

Projects

A project is a named workspace for related work. It is not the same as a conversation (one chat thread), a mission (one job), a session (one running attempt), an artifact (one output file), or a run (one execution). Your home folder stays the home project unless you switch.

Drafts — saved automatically, kept across refreshes

Write here, save, and come back later — drafts survive a refresh or a crash. Use the up and down arrow keys in the box to step through earlier drafts. Templates fill in the blanks you name; anything missing is listed, never guessed.

Schedules

Recurring schedules below come from the schedule engine. One-time runs, reminders, and triggers live in the workbench too, with a preview and a dry run that creates nothing.

Approvals waiting for you

Each approval says what is asked, why, what it touches, whether it can be undone, and what happens if you say no. You can approve once, approve for this mission, reject, or inspect — never everything at once.

System health

Checks this app can actually run. A health report you export never includes keys, full prompts, or private files — preview it first.

Deleting things — what actually goes, and what stays

Deleting here removes the workbench record you name. Exports you already downloaded, records held by providers, backups you created, and server logs are NOT erased by it — they need separate handling.
