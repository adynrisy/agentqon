```

I need a complete working application built through conversation, not coding.

- Deployment pipeline: push to production with one command using Vercel, Railway, or Fly.io
- Iteration protocol: how to request changes, new features, and improvements through conversation rather than code

Format as a vibe coding playbook with Cursor setup instructions, prompt patterns for each development phase, and best practices for conversational development.

My app: [DESCRIBE YOUR APPLICATION IN PLAIN ENGLISH — WHAT IT DOES, WHO USES IT, AND THE KEY FEATURES YOU NEED]
```
