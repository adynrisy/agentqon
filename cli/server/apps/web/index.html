AI connections (BYOK)

Connections come in two kinds: a local model server on your own machine (no API key), or an API-key (BYOK) connection to any provider or gateway — either kind can use any address, including one on your own machine. Keys are encrypted server-side and shown only masked — after saving, nobody (including this UI) can read them back. Prompts go to the endpoint you choose; the provider bills your account. Confidential missions only route to local endpoints or connections you explicitly allow.
Pick a provider and its address fills in — fewer wrong addresses, fewer failed connections. Custom always works too.
Advanced headers — extra headers sent with every request to this provider. Most providers need none; a few (like AgentRouter) only answer clients that identify themselves a certain way.
Stored like your API key — after saving, the values are never shown again.

Model combos

A combo is a named chain of models. Pin a combo in the model picker — or map a model-name pattern to one below — and when a provider fails, runs out of quota, or stops answering, the call moves to the next model in the chain automatically; the move is written into the mission's minutes. The Auto combo is always in the picker: every connected model, scored live.

Model mappings

When a run asks for a model whose name matches a pattern, the mapped combo serves it instead. Patterns use * as a wildcard (for example gpt-*). The lowest priority number wins.
