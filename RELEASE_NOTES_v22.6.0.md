# AgentQon v22.6.0 — release notes (prepared 2026-10-28)

Status: LIVE ON NPM.

## Install / update

agentqon stop

npm install -g agentqon@latest

agentqon setup

agentqon

## What changed

### The activity panel, mirrored on Muse

- An app-wide activity center in the right panel: a Today-style
  feed with a status mark, a plain-words title, a short result
  line and a time per row — covering work across the whole app,
  not only missions and not only agent sessions. Click a task to
  see its files.
- The personified computer character sits at the top of the
  panel, in the same place as Muse's avatar.

### Composer file attachments

- Attach files to a chat message from the composer.

### Societies list, fixed

- The societies list endpoint no longer fails with a server
  error; the list loads.
