# AgentQon documentation

Every guide, in the order you'd want them. All of it is written the
way the product talks: plain words, nothing readable two ways.

## Start here

1. **[Installation](installation.md)** — every platform, requirements,
   updates, uninstall.
2. **[Connecting models](connecting-models.md)** — the only two kinds
   of connection there are: a local model server, or an API key.
3. **[Getting started](getting-started.md)** — zero to your first
   critic-verified mission in about five minutes.
4. **[Your first mission](first-mission.md)** — the same journey as a
   step-by-step tutorial, with an example brief and what to read in
   the result.

## Work deeper

- **[Agent sessions](agent-sessions.md)** — agents that use tools:
  files, commands and the web, inside a workspace, under your
  approval, with the claim guards explained.
- **[Skills](skills.md)** — the 5,053-skill library: how automatic
  retrieval works, and what pins do.
- **[Model self-test](model-self-test.md)** — one click that proves
  which of your models actually answer, and what each stamp means.
- **[Society simulation](society.md)** — the simulated room of 100
  agents: how sizing works, how to read the graph, and what the
  output does and does not mean. A simulated estimate, never a
  prediction.

## Reference
