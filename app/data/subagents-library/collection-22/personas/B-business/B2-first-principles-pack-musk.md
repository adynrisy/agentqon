# 🔬 First Principles Pack (Musk)

> **Use when:** You need to break assumptions, disrupt industries, or find unfair advantages.

### Prompt 1: The Assumption Killer
```
"I currently believe [YOUR BELIEF]. Rip this apart using only first principles. Separate what's actually true from what I believe just because everyone around me believes it. Be ruthless."
```

### Prompt 2: The Industry Disruptor
```
"Pretend [INDUSTRY] doesn't exist yet. If we were inventing it from zero today using only current technology and physics, what would we build? Throw out every legacy system and convention."
```

### Prompt 3: The Brutal Honesty Mirror
```
"I'm working on [YOUR PROJECT/IDEA]. Don't encourage me. Tell me the top 5 reasons this will fail, what I'm blind to, and what my competitors see that I don't. Be painfully honest."
```

### Prompt 4: The Crowd Is Wrong Detector
```
"What does the majority of people believe about [TOPIC]? Now prove them wrong using data, logic, and first principles. Show me where popular opinion is broken."
```

### Prompt 5: The Complexity Destroyer
```
"Explain [COMPLEX TOPIC] to me as if you're rebuilding it from atoms. No jargon. No history. No 'the way it's always been done.' Just the raw logic of how it actually works."
```

### Prompt 6: The 10x Cost Cutter
```
"Break down every single component and cost behind [PRODUCT/SERVICE]. Now show me where there's a 10x gap between what something costs today and what it SHOULD cost based on raw materials and first principles."
```

### Prompt 7: The Weekend MBA
```
"Teach me [BUSINESS CONCEPT] the way you'd explain it to a brilliant 12-year-old. Use real-world examples, zero textbook language, and make it impossible to forget."
```

### Prompt 8: The Decision Multiplier
```
"I need to choose between [OPTION A] and [OPTION B]. Analyze both using second-order thinking. Don't just tell me what happens next — tell me what happens after what happens next. Map out the consequences 3 levels deep."
```

### Prompt 9: The Unfair Advantage Finder
```
"I'm building [YOUR PROJECT]. What is the one unfair advantage I could develop that would be nearly impossible for competitors to copy? Think about what took Musk 10 years to build at Tesla that no one can replicate overnight."
```

### Prompt 10: The Future Predictor
```
"Based on current technological trends and exponential growth curves, what will [YOUR INDUSTRY] look like in 5 years? What will be obvious in hindsight that almost nobody is paying attention to right now?"
```
