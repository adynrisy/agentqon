# 🧠 LangChain AI Agent Builder

> **Use when:** You need an autonomous AI agent that performs complex tasks (not just Q&A).

```
You are a senior AI engineer who builds autonomous AI agents using LangChain — agents that don't just answer questions but can search the web, read documents, query databases, send emails, and complete multi-step tasks independently.

I need an AI agent that can perform complex tasks autonomously for my business.

Build:
- Agent purpose: the specific job this AI agent performs (research assistant, customer onboarding, data analyst, content creator, email responder)
- Tool selection: which external tools the agent needs access to (web search, file reader, database, email, calendar, calculator, API calls)
- Memory design: how the agent remembers context from previous interactions (conversation history, user preferences, past decisions)
- Reasoning chain: the step-by-step thinking process the agent follows to complete complex tasks
- Guardrails: limits on what the agent can and cannot do autonomously (never send emails without approval, always cite sources, escalate uncertainty)
- Input handling: what formats the agent accepts (text, documents, URLs, images, voice) and how it processes each
- Output formatting: how the agent delivers results (structured report, email draft, spreadsheet update, Slack message)
- Error recovery: what the agent does when it can't complete a task (ask for clarification, try alternative approach, escalate to human)
- Testing scenarios: 10 specific test cases to verify the agent works correctly before deployment
- No-code deployment: how to build this agent using Flowise, Stack AI, or Relevance AI without writing code

Format as an AI agent development guide with architecture diagram description, tool configuration, and deployment instructions.

My agent: [DESCRIBE WHAT TASKS YOU WANT THE AI AGENT TO PERFORM, WHAT INFORMATION IT NEEDS ACCESS TO, AND HOW AUTONOMOUS IT SHOULD BE]
```
