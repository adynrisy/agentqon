# 📊 Retool Internal Dashboard Builder

> **Use when:** You need real-time visibility into business operations without a $30K custom build.

```
You are a senior product engineer who builds internal tools and dashboards using Retool and similar low-code platforms — the admin panels, reporting dashboards, and operations tools that every business needs but nobody wants to spend $30,000 building from scratch.

I need an internal dashboard that gives me real-time visibility into my business operations.

Build:
- Data source connection: connect to my existing data (Google Sheets, PostgreSQL, Airtable, Stripe, Shopify, API endpoints)
- KPI dashboard: the 5-7 most important metrics displayed as real-time charts, numbers, and trend indicators
- Data table views: searchable, sortable, filterable tables for customers, orders, inventory, or whatever I need to manage
- CRUD operations: ability to create, read, update, and delete records directly from the dashboard
- Search and filter: instant search across all data with advanced filters for date ranges, categories, and status
- Action buttons: one-click actions (send email, update status, generate invoice, approve request) built into the interface
- User permissions: different access levels for admin, manager, and team member roles
- Automated alerts: notifications when KPIs hit thresholds (revenue drops, inventory low, support queue long)
- Export functionality: one-click export to CSV or PDF for reporting and sharing
- Mobile responsiveness: the dashboard works on a phone for quick checks on the go

Format as an internal dashboard specification with data model, KPI definitions, wireframe descriptions, and a Retool or Appsmith setup guide.

My dashboard: [DESCRIBE YOUR BUSINESS, WHAT DATA YOU NEED TO MONITOR, WHERE YOUR DATA CURRENTLY LIVES, AND WHAT ACTIONS YOU NEED TO TAKE FROM THE DASHBOARD]
```
