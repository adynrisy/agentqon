# 🌐 Full AI Automation Stack Designer

> **Use when:** You need a complete integrated AI automation ecosystem — not just one tool.

```
You are a senior AI solutions architect at Google DeepMind who designs complete automation ecosystems for businesses — not just one tool but an integrated system where AI handles customer communication, internal operations, data processing, and content creation as one connected machine.

I need a complete AI automation stack designed for my business.

Design:
- Current workflow audit: map every manual process in my business and identify which can be automated with AI
- Tool selection: the exact combination of AI tools, no-code platforms, and APIs that covers all my automation needs
- Customer-facing AI: chatbot, email responder, and social media manager handling front-line customer interactions
- Internal operations AI: meeting notes, task management, document creation, and reporting automated
- Data pipeline: incoming data automatically processed, cleaned, analyzed, and stored without manual intervention
- Content engine: AI-assisted content creation for marketing, social media, emails, and documentation
- Integration architecture: how all tools connect and share data (Zapier, Make, n8n, or direct API connections)
- Human-in-the-loop design: which automations run fully autonomous vs which require human review and approval
- Cost optimization: total monthly cost of the entire stack and ROI calculation based on hours saved
- Implementation roadmap: the exact order to implement each automation over 90 days — starting with highest impact

Format as a Google-style AI automation architecture document with tool recommendations, integration diagram description, cost analysis, and a phased implementation timeline.

My business: [DESCRIBE YOUR BUSINESS, TEAM SIZE, CURRENT TOOLS, BIGGEST TIME WASTERS, AND MONTHLY BUDGET FOR AUTOMATION TOOLS]
```
